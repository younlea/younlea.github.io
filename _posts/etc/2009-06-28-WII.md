일단 기분깔끔하게 초기화기켜 시켰구요( 초기화시키니까 버전 3.3가 되더군요)

3.3k 버전은 40번 자료를 그냥 실행시키면 홈브류 들어갈때 튕기더라구요~

유틸자료실에 40 /16 번 두개 다운받으시면 되구요

-- 컴퓨터서 할일

1. SD카드 usb 연결하고 40번 자료로 실행  "install.bat" -> "o" -> "sd카드 드라이브명" -> "y"

요렇게 키보드 3번만 두드리면 되구요

2. 16번 자료(WAD Manager 1.3)를 SD카드 apps 폴더에 넣으면 되구요.

SD카드에 "IOS36-64-v1042.wad" 란 파일을 "wad"폴더 에 카피해줍니다.

--  위로 넘어감

-> wii -> chennel -> SD Card\

3.  위에 sd카드 넣고 킨다음 위메뉴가서 채널에서 SD선택하시면 부팅하겠나고 합니다. OK하시구

폴더들이 나오는데 '2'번에서 설치한   WAD Manager 1.3실행하기 위해서 APPS 들어가서 WAD Manager 1.3들어가서

실행합니다. 나오는 항목중에 "2"번에서 카피한 IOS36-64-v1042항목이 나올겁니다.

'+'버튼 누르셔서 설치하시고

아까 폴더들 메뉴로 돌아오면

맨밑에 WADBatchInstaller 실행하시면 홈브류가 실행되실껍니다.

4. 위 재부팅 되고 홈브류로 들어가지면

cIOS36 rev10 Installer 실행하고

cMIOS rev3 Installer 실행하시면 끝입니다.
