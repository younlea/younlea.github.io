1. 우선 samba를 받는다.

sudo apt-get install samba

2. smbpasswd를 셋팅한다.

sudo smbpasswd -a [user-id]

3. 공유폴더 셋팅 한다.

gedit  /etc/samba/smb.conf

아래 내용을 넣는다.

[temp]             #<< 공유할 folder 이름

path = /temp   #<< path    이건 절대 루크가 들어가야 한다. 예로 **path=/home/id**

**ㅜㅜ ~/ temp <<  이런거 절대 안된다 ... /home/id/temp 이렇게 해야 한다 ㅡ.ㅡ;**

writable = yes    # write 할수 있는 지 없는지 권한

valid users = tam  # tam이 접근할수 있게 한다. (모두다 쓸수 있게 하려면 이 라인을 지워버리면 됨.)

4. 공유하기로한 /temp folder의 권한을 바꿔야 한다.

sudo chmod 777 temp

sudo chown nobody temp

5. restart samba service

sudo /etc/init.d/smbd restart

\\아이피로 접근이 가능하다..
