Activity가 없이.. 그러니까. 화면에 나오지 않고 background 로 동작한다.

명시적 service  및 암시적 service가 있다.

명시적인 경우

Semple.java

Intent service = new Intent(Semple.this, MyService.class);

startService(service);

<service android:name=".Myservice">

MyService.java

public void onCreate() {

}

public void onStart(Intent intent, int startId) {

}

public void onDestroy() {

}

public IBinder onBind(Intent intent) {

}

암시적인 경우

Intent service = new Intent("com.sulac.service.test");

startService(service);

<service android:name=".Myservice">

<intent-filter>

<action android:name="com.sulac.service.test"/>

<category android:name="android.intent.category.DEFAULT"/>

</intent-filter>

</service>

service.jave 는 동일함.
