**기본 치트키**

tgm - 무적 모드(체력, 마나, 무게등의 제한이 없어진다.)\
tim - 죽지 않음(만약 게임 플레이도중 피니쉬로 목이 날아갈 경우 목이 없는 채로 생존)\
tcl - 자유로운 이동이 가능함(벽이나 산 같은 곳에 방해 받지 않음. 날아다닐 수도 있다.)\
tm - 게임의 메뉴를 없애준다.\
psb - 모든 마법과 용언 획득(용언은 활성화 되어 있지 않다.)\
tmm(1) - 모든 맵마커 활성화(tmm(0)으로 비활성화 시킬 수 있다.)\
coc “지역이름” - 원하는 지역으로 순간이동\
tfc - 자유로운 시점으로 변경 가능 \
qqq - 게임 종료\
help - 모든 치트 코드를 알려준다.\
heip "아이템 이름"4 - 해당 아이템의 아이템 코드를 알려준다.\
coc qasmoke - 모든 아이템이 있는 구역으로 순간이동(구역을 나올때도 코드를 입력 해야 한다)\
sexchange - 캐릭터의 성별을 바꿈(조심해야 할 점은 얼굴만 바뀜)\
movetoqt - 선택된 퀘스트로 이동\
tdetect - 물건을 훔치거나 NPC를 공격해도 들키지 않음\
duplicateallitems - 아이템 복사(해당 아이템의 코드를 알아야 하며 NPC도 복사 된다.)\
player.equipitem“아이템코드” - 해당 아이템을 착용한다\
player.moveto“NPC 코드” - 해당 NPC로 순간이동\
player.placeatme“NPC 코드” - 헤당 NPC를 캐릭터 옆으로 소환\
fov“숫자” - 시야 변경(기본 최대시야가 75로 설정 되어 있으며 85~95사이가 적당하다.)

**스킬 및 능력치 조절 치트키**\
player.advlevel - 강제 레벨업(퍽은 추가 되지 않는다.)\
player.teachword "용언 코드" - 해당 용언 추가\
player.modav carryweight"숫자" - 소지가능한 무게를 변경 한다.\
player.modav dragonsouls"숫자" - 드래곤 소울 추가\
player.setav speedmult"숫자" 움직이는 속도를 변경 한다.\
player.setav stamina"숫자" - 스테미나 수치 변경\
player.setav health"숫자" - 생명력 변경 \
player.setav magicka"숫자" - 메자카 변경 \
player.setlevel"숫자" - 캐릭터의 레벨 변경.\
player.setcrimegold"숫자" - 현상금 변경\
player.placeatme"NPC코드" - NPC 소환\
player.incPCS“스킬” - 해당 스킬 1단계 레벨업\
player.additem"아이템코드"“숫자” - 해당 아이템을 입력한 숫자 만큼 추가 시킨다.\
player.additem f"숫자" - 골드 추가\
player.additem a"숫자" - 락픽 추가\
player.addperk"퍽 코드" - 해당 척 추가
