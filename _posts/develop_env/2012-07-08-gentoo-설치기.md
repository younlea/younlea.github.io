gentoo    : 146MB    [<http://www.gentoo.org/main/en/where.xml>]

움.. 우선 gentoo를 받고 VMware로 설치를 한다..

설치하면... 프롬프트창만 뜨는데.. 이게 시작이다..

eth0가 없어서 ㅡ.ㅡ;

#net-setup eth0 로 eth0 setting해서 완료.

ifconfig 쳐보면eth0가 잘 올라온걸 알수 있다.

ssh를 뚫기 위해...

#/etc/init.d/sshd start 하면 ssh가 뚫린다.

#passwd 로 password도 지정해야 한다.

이후 putty로 접속을 할때는 ifconfig로 ip 확인하고 ID : root  PW : 지정한 password 접속..
