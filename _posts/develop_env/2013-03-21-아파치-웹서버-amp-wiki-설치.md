아파치 설치 순서

$sudo apt-get install apache2   << 설치가 끝난다 허무..

서버 상태 확인

$ sudo service apache2 status

Apache2 is running (pid 23514).

$ sudo netstat -lntp | grep apache2

tcp        0      0 0.0.0.0:80              0.0.0.0:\*               LISTEN      23514/apache2

$ /etc/init.d/apache2

이 상태에서 server에서 127.0.0.1에 접속하면 아래와 같이 나온다.

![image](/assets/images/posts/5730619/c0028014_515c4c73335b0.jpg)

움 이렇게 하고 나서...  iptime에서 포트 포워드로 80 포트에 대해서 포트 포워딩을 하고

IP time의 DDNS 기능을 이용해서

xxxx.iptime.org:80 으로 하면 외부에서 웹싸이트 접속이 가능해 진다.

아래 세개의 파일에서 setting들을 한다

/etc/apache2/apache2.conf

/etc/apache2/httpd.conf

/etc/apache2/ ports.conf

80번 포트도 실제로는 ports.conf 안에 아래와 같이 선언되어있다.

NameVirtualHost \*:80

Listen 80
