Ubuntu 10.4를 설치하고 window PC에서 접근을 하는데 putty로 접근시 

putty network error connection refused  에러가 난다...

이 에러가 왜 났을까???? 

결국 ubuntu에서 ssh가 설치가 안되어서 접근이 안되었다... 으흐흐

apt-get update 한 후에 .. 해야함.

-----------------------------------------------------------

apt server setting을 해줘야 함..

# sudo -s

# cd /etc/apt

# cp sources.list sources.list.backup

# vi sources.list

  :%s/kr.archive.ubuntu.com/ftp.daum.net/g

  wq

# apt-get update

-----------------------------------------------------------\

sshd를 치면... 아래와 같이 설치하라는 문구가 친절히 나온다 ^^;\
apt-get install openssh-server

자 그럼 인스톨을 하면..\
ssh localhost를 치면 상태를 확인할수 있다는데..모 인스톨 이후에 putty에서 접속이 잘된다. 흐흐흐. 

linux PC에서 잘되는지 확인은 아래와 같이 접속해서 되면 된단다.\
# ssh localhost\
root@localhost's password: 

실행중이 아니라면 아래 명령을 내리면 된다고 하는군.\
sshd start

[sudo /etc/init.d/ssh restart ]\
