ipad에서 code를 보려구 vscode server를 설치 했었는데. 이것보다 더 좋은게 있어서 정리 합니다.

gitpod.io 라는 건데...

web browser에서 원하는 github 주소를 아래와 같이 넣으면 web browser에서 vscode처럼 쓸 수 있습니다.

(월 50시간 무료~ 잠깐 잠깐 코드 볼 때는 좋을듯 합니다. 아 gitlab도 된다구 합니다. )

gitpod.io#[github주소]

example) 원하는 github 주소 : https://github.com/google/googletest

접속 방법 ) gitpod.io/#https://github.com/google/googletest

추신 : 훔.. 아무래도 docker같은 마이크로 서버를 그때그때 생성해 주는것 같습니다.

전 집에 서버를 설치해서 크게 필요는 없으나 세상이 참 빨리 바뀌는 걸.. 서비스가 얼마나 중요한지 알게 되는 단상이라 공유합니다.
