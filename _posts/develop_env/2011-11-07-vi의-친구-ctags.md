우선.. 설치부터 해보자

sudo apt-get install ctags 하면된다.. ^^;

기본사용은 tag를 만들고 싶은곳에 가서 ctags -R 하면 tags가 생긴다.

그리고 vim을 사용하여 찾아갈수 있게 된다.

기본 사용법.

vi -t [function] : function이 선언된 부분으로 vi창을 연다.

소스에서 function의 선언부를 찾으려면 함수위에서 ctrl + ] 를 누르면 되고\
다시 원래 코드로 가려면 ctrl+t를 누르면 된다.\
:tj [function] <= function이 있는 곳으로 점프 한다\
:sts [function] <= function 이 있는 곳으로 창을 수평분할해서 점프한다.
