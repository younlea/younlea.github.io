비행을 직접 하기 전에 시뮬레이터를 사용해서 비행연습을 사전에 하는것이 좋습니다.

[알리 구매 링크](https://www.aliexpress.com/item/Niosung-New-All-20in1-Flight-Simulator-Cable-USB-Dongle-for-RC-Helicopter-Aeroplane-Car/32728228529.html?spm=2114.13010608.0.0.KWgk5f)

독자 분들이 구매한 turnigy 9x에도 연결해도 되고 다른 조종기에도 연결해서 사용할수 있는 동글입니다.

일단 최근에 구매한 FlySky FS-i6 2.4G 6ch을 연결해서 셋팅하는 법을 설명하겠습니다.

조종기에 연결합니다.

![image](/assets/images/posts/6144850/c0028014_594d1b6de396c.jpg)![image](/assets/images/posts/6144850/c0028014_594d1b8079523.jpg)![image](/assets/images/posts/6144850/c0028014_594d1b8a04f99.jpg)

![image](/assets/images/posts/6144850/c0028014_594d1b92179c6.jpg)

자 PC와의 연결은 되었고 이제 같이 들어 있는 CD를 넣고 설치를 하게 됩니다.

![image](/assets/images/posts/6144850/c0028014_594d1baa35237.png)

영어를 선택하시구요 ^^;

![image](/assets/images/posts/6144850/c0028014_594d1bb6d3323.png)

저 같은 경우는 RealFlight G7 정품을 구매해서 연습했었습니다.

위에 보시면 첫째로 Install Dirver DirectX90c를 설치하시구요..

그 이후는 5가지중 한가지의 시뮬레이터를 선택하셔서 설치하면 됩니다.

일단 RealFlight를 설치해 보겠습니다.

![image](/assets/images/posts/6144850/c0028014_594d1c0dcd006.png)

계속 next를 눌러 주십니다. ^^;

![image](/assets/images/posts/6144850/c0028014_594d1c21aa07b.png)

다 선택하시구 계속 설치를 합니다.

![image](/assets/images/posts/6144850/c0028014_594d1c3611e21.png)

설치가 완료 되었습니다.

이제 설치한 폴더에 가서 실행을 합니다.

![image](/assets/images/posts/6144850/c0028014_594d1c5122f0d.png)

일단.. 실행하기 전에 바탕화면에 있는 아래 파일을 실행합니다.

![image](/assets/images/posts/6144850/c0028014_594da5bfb508a.png)

그리고 launcher를 실행하면 아래와 같이 시리얼 넘버를 등록하는 문구가 나옵니다.

![image](/assets/images/posts/6144850/c0028014_594da5d1ef11d.png)

해당 CD에 있는 두개의 번호를 입력합니다. (저는 정품이라서 케이스에 있는 번호와 조종기에 있는 번호를 입력했습니다.)

![image](/assets/images/posts/6144850/c0028014_594da61d582d7.png)

이후 다시 실행하면 실행과 Run RealFlight 버튼 아래에 option이 있는데 그걸 누르면 아래와 같이 펼쳐집니다.

![image](/assets/images/posts/6144850/c0028014_594da616f3126.png)

7.0 에서 7.5로 업데이트를 해야해서 Registration/updates를 눌러서 진행합니다.

feiying simulator launcher에서 보인 passward를 맞춰서 입력하면 무난히 넘어 갑니다.

![image](/assets/images/posts/6144850/c0028014_594da675b7fe3.png)

업데이트후 실행하면 됩니다. 6^^;

![image](/assets/images/posts/6144850/c0028014_594d1c74b4974.png)

실행하시면 바로 비행기가 움직이면서 사고가 날겁니다. ^^;

이제... 조종기 셋팅을 합니다.

![image](/assets/images/posts/6144850/c0028014_594d1c997b4b3.png)

simulation -> select controller 선택하시면 위와 같은 조종기 선택 화면이 나옵니다.

위에 interlink를 선택해 주시고 시작하면 동작이 잘 될겁니다.

제대로 동작을 안할 경우 edit로 방향을 맞추고 calibration으로 초기화를 맞추면 잘 사용할 겁니다.

마지막으로 말씀드릴것은 해당 정품을 사시는걸 추천드립니다. ^^;

프로그램만 12만원 정도 합니다.

너무 비싸다면 freeware를 사용하시는 방법도 있습니다.

freeware의 경우 찾아서 다시 공유해 드리도록 하겠습니다.
