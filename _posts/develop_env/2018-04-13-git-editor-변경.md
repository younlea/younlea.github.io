git으로 commit할때 editor가 쓰던게 아니라서 불편한데..

저는 vim을 사용하고 있어서.. vim으로 셋팅하여 쓰고 있습니다.

git config --global core.editor vim

불편한데 적응하면서 살지 말고 살짝 바꿔서 사용해 보시길 ^^;
