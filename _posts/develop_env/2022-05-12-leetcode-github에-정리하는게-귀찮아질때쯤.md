leethub 라는 걸 누군가 만들었더군.. .

<https://github.com/QasimWani/LeetHub>

사용법은 간단하다.

Chrome extention에  leethub 를 설치하고 실행하면 github에 본인의 repo에 만들어서 연결을 해준다.

이후 leetcode에서 문제를 풀면 자동으로 해당 repo로 문제 당 하나의 폴더를 만들면서 정리해 준다.

![image](/assets/images/posts/6911211/c0028014_627c248a2a573.png)

편하긴 한데.. 이전에 푼것들을 자동으로 씽크를 하거나 특정 repo에 정해진 하위 폴더에 정리하는 기능은 아직인것 같다.

그래도 open source 활동을 활발히 하고 있는걸로 보이는데. 해당 기능을 issue로 올린 사람들이 있어서 추후 update 를 기대하게 된다.
