JDK1.6 download를 google 링 해서..

sun site에 접속

JAVA SE 6 Update 29 옆에 JDK download를 클릭. 다운로드 받고

Installation을 클릭해서 Linux - RPM\_Linux\_64-bit의 Self-Extracting\_Linux64-bit를 보면 설치 방법이 나와있다.

보편적으로 아래 folder에 설치를 한다..

/usr/lib/jvm

다운로드 받은 파일을 위 folder에 copy

chmod 755 jdk..... bin

sudo ./jdk-...bin

(위와 같이 하면 압축이 자동으로 풀림.)

이제 path를 설정해 줘야 할때..

sudo gedit /etc/profile & <- path 추가.

제일 아래

JAVA\_HOME=/usr/lib/jvm/jdk1.6.0\_29

PATH=$JAVA\_HOME/bin:$PATH

source /etc/profile  <-profile 적용

echo $PATH < -path를 확인

java -version <- version을 확인.

참고로.. apt-get으로 받을수도 있다고 한다 ㅡ.ㅡ; 왜 안되는진... ㅡㅜ
