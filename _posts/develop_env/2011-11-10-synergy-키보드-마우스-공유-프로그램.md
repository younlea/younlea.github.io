1. Window PC와 Ubuntu PC에 깐다.

2. Window PC는 configuration server를 눌러서 linux cmd로 hostname을 쳐서 이름을 알아내고 추가한다.

3. Ubuntu에서는 quicksynergy에서 USE 밑에 server IP를 넣고 screen name에 Ubuntu PC 이름을 넣는다.

이렇게 해서 실행했는데 안되면..

ubuntu에서 synergyc [server PC IP] 명열을 넣으면 동작한다..

windows를 server로 사용할때 configure에 들어가서 screens 두개를 입력해 주고

links에서 두개에 대한 설명이 있어야 한다.

1. window의 오른쪽은 linux

2. linux의 왼쪽은 windows

모 이런식으로...

그림은 생략한다.. ^^;
